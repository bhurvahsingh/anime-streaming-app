# Building AnimeHub APK\n\n## Prerequisites\n\nBefore building the APK, install the following:\n\n### 1. Node.js & npm\n```bash\n# Download from https://nodejs.org/\nnode --version\nnpm --version\n```\n\n### 2. Java Development Kit (JDK)\n```bash\n# For Windows/Mac/Linux\n# Download JDK 11 or higher from https://www.oracle.com/java/technologies/javase-jdk11-downloads.html\n\njava -version\njavac -version\n```\n\n### 3. Android SDK\n```bash\n# Download Android Studio from https://developer.android.com/studio\n# Or install Android SDK command-line tools\n\n# Set ANDROID_SDK_ROOT environment variable:\n# Windows: set ANDROID_SDK_ROOT=C:\\Users\\YourUsername\\AppData\\Local\\Android\\Sdk\n# macOS/Linux: export ANDROID_SDK_ROOT=~/Android/Sdk\n```\n\n### 4. Gradle\n```bash\n# Usually comes with Android Studio\n# Or install separately from https://gradle.org/install/\n```\n\n## Build Steps\n\n### Step 1: Install Cordova\n```bash\nnpm install -g cordova\n```\n\n### Step 2: Run the Build Script\n```bash\nchmod +x build-apk.sh\n./build-apk.sh\n```\n\nOr for Windows (PowerShell):\n```powershell\n# Run the build commands from build-apk.sh manually\ncordova create cordova-app com.animehub.app AnimeHub\ncd cordova-app\ncordova platform add android\ncordova plugin add cordova-plugin-whitelist\ncordova build android --release\n```\n\n### Step 3: Sign the APK\n\n**Create a keystore (if you don't have one):**\n```bash\nkeytool -genkey -v -keystore animehub.keystore -keyalg RSA -keysize 2048 -validity 10000 -alias animehub\n```\n\n**Sign the APK:**\n```bash\njarsigner -verbose -sigalg SHA256withRSA -digestalg SHA-256 \\\n  -keystore animehub.keystore \\\n  cordova-app/platforms/android/app/build/outputs/apk/release/app-release-unsigned.apk \\\n  animehub\n```\n\n**Align the APK:**\n```bash\n# Find zipalign in Android SDK\n# Usually at: $ANDROID_SDK_ROOT/build-tools/[version]/zipalign\n\nzipalign -v 4 app-release-unsigned.apk app-release-signed.apk\n```\n\n### Step 4: Verify the APK\n```bash\nzip -vf app-release-signed.apk | head -20\n```\n\n## Output\n\nThe signed APK will be at:\n```\ncordova-app/platforms/android/app/build/outputs/apk/release/app-release-signed.apk\n```\n\n## Distribution\n\n### Option 1: Direct Installation (Testing)\n```bash\nadb install app-release-signed.apk\n```\n\n### Option 2: Google Play Store\n1. Create a Google Play Developer account\n2. Follow their publishing guide\n3. Upload the signed APK\n\n### Option 3: Direct Download\n- Host on your server\n- Share APK file directly\n- Users can install by enabling \"Unknown sources\"\n\n## Troubleshooting\n\n### Build Fails with Gradle Error\n```bash\n# Update Gradle\ncd cordova-app\ngradle wrapper --gradle-version 7.4\n```\n\n### SDK Not Found\n```bash\n# Set Android SDK path\nexport ANDROID_HOME=$HOME/Android/Sdk\nexport PATH=$PATH:$ANDROID_HOME/tools:$ANDROID_HOME/platform-tools\n```\n\n### APK Won't Install\n- Check if target device has minimum SDK 22 (Android 5.1)\n- Enable \"Unknown sources\" in device settings\n- Try uninstalling old version first\n\n## Testing on Device\n\n### Connect via ADB\n```bash\nadb devices\nadb install app-release-signed.apk\n```\n\n### Test on Redmi 6A\n1. Enable Developer Mode (tap Build Number 7 times)\n2. Enable USB Debugging\n3. Connect via USB\n4. Run: `adb install app-release-signed.apk`\n5. Launch AnimeHub from app drawer\n\n## APK Size Optimization\n\nThe built APK is already optimized:\n- ✅ Cordova lightweight (~8-12 MB)\n- ✅ No heavy frameworks\n- ✅ Minified JavaScript/CSS\n- ✅ Compression enabled\n\nTypical size: **~15-20 MB**\n\n## Configuration\n\nEdit `config.xml` to customize:\n- App name: `<name>AnimeHub</name>`\n- Package ID: `id=\"com.animehub.app\"`\n- Version: `version=\"1.0.0\"`\n- Permissions: `<access>` tags\n- Screen orientation: `<preference name=\"orientation\">`\n\n## API Configuration\n\nIn `cordova-app/www/index.html`, update:\n```javascript\nconst API_URL = 'http://your-server-ip:3000/api';\n```\n\nChange `your-server-ip` to your actual server address.\n\n## Security\n\n- ✅ HTTPS recommended for production\n- ✅ API authentication via JWT tokens\n- ✅ SSL certificate pinning (optional)\n- ✅ Secure storage for tokens using Cordova plugins\n\n## Support\n\nFor issues:\n1. Check Cordova documentation: https://cordova.apache.org/\n2. Check Android Studio logs\n3. Review build errors carefully\n\n---\n\n**Ready to build? Run: `./build-apk.sh`** 🚀\n
